# Seoul Family Winter Edition — Booking / Studio UX Revision

- Studio shell keeps Trip Management, Export Centre, Data Control, and Leave Studio Mode.
- New Booking action moved to the Booking page (`trip.html`) and appears when Studio Mode is unlocked. The existing form and link-to-Day/Guide behavior are preserved.
- `Publish Latest Trip` is removed from the local-first generated pages. Days: Edit → Save Changes commits to the current browser's local storage immediately.
- No cloud or cross-device Save & Sync is enabled in this 25.6.9 Beta. Other devices do not receive edits automatically.
- Original winter logo/theme, the 9-day itinerary, four users, and AUD/Melbourne configuration are preserved.
- Export Centre functionality is retained; its Memory Book choices are inherited from the legacy runtime and depend on configured memory data.
- Studio Create Booking is not a traveler's public action: unlock Studio Mode then open Booking page.
