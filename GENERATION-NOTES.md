# Generated Trip Companion

This app was generated from the neutral Travel Engine 25.6.4 starter. Local-first mode, without shared cloud sync. Studio, Booking, Days, Guide and Expenses are the inherited 25.6.4 behavior. Booking creation remains limited by the legacy authority.

Trip seed: `trip-seed.json`. Edit in the Engine generator and rebuild to change initial data. Post-trip add a `memoryBookUrl` to the seed to show **Our Memories** after the trip.

Never deploy with a real private access code inside JavaScript: the current Studio PIN is client-readable and is not server security.
