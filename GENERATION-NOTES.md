# Generated Trip Companion

Generated by Travel Engine 25.6.9 from its neutral starter. Local-first mode without shared cloud sync. Studio creates Booking records and links them to Days/Places in the local browser. Existing Expenses and Booking payment links remain available.

Trip seed: `trip-seed.json`. Edit in the Engine generator and rebuild to change initial data. The Studio Archive panel can save an optional Memory Book URL on this device; `memoryBookUrl` in the seed sets the initial link across deployments.

Never deploy with a real private access code inside JavaScript: the current Studio PIN is client-readable and is not server security.
